# 视觉系统规范

本文档定义「AI 掼蛋成长训练 App」的视觉系统。目标不是做课程网站、后台工具或普通棋牌大厅，而是做一个移动端优先、每天可打开、由 AI Coach 陪练的竞技成长训练 App。

## 1. 品牌视觉定位

目标感觉：

- 专业：用户相信这里的训练判断是可靠的。
- 竞技：每次训练像一次小挑战，而不是读一篇文章。
- 成长：用户能看到 XP、等级、连续训练和能力提升。
- AI 陪伴：Ace / AI Coach 是训练中枢，不是装饰头像。

关键词：

- AI 教练
- 竞技训练
- 成长反馈
- 陪练体验
- 战术清晰
- 每日挑战

避免：

- 企业后台感：不要像数据管理系统。
- 普通课程网站感：不要把页面做成课程列表和文章详情。
- 棋牌大厅感：不要做成开局、匹配、充值、房间入口。
- 幼稚游戏感：可以游戏化，但不要儿童化。
- 赌场感：避免厚重木纹、筹码、赌桌、金色堆叠。

视觉参考方向：

- Chess.com 的训练任务感。
- Duolingo 的成长反馈，但更克制。
- Linear / Vercel 的清晰信息层级。
- 科技训练舱的深色、边框、能量槽和任务面板。

## 2. 色彩系统

色彩目标：

> 深色科技训练场 + 掼蛋牌局文化 + 成长游戏反馈。

### 2.1 核心色板

```txt
App Background: #0B1020
Arena Background: #101827
Panel Surface: #151D2E
Panel Elevated: #1B2538
Panel Soft: #202B40

Primary Energy Yellow: #F6C65B
Primary Energy Deep: #C9972E
Tech Blue: #4DA3FF
Tech Cyan: #54D7FF

Poker Red: #F05252
Tactical Green: #45D483
Reward Gold: #FFD36A
Warning Red: #FF6B6B

Text Primary: #F8FAFC
Text Secondary: #A8B3C7
Text Muted: #6F7B91
Border Default: #2A3448
Border Active: #F6C65B
```

### 2.2 使用规则

背景色：

- 主背景使用深蓝黑，不使用纯黑。
- 可使用微弱径向光、细网格、低透明边框表达训练场。
- 背景不能抢牌桌、训练卡和 Coach 的注意力。

主色：

- 能量黄用于主 CTA、当前任务、XP、重要进度。
- 面积要克制，避免廉价页游感。
- Ace 的黄色识别应与主色呼应。

辅助色：

- 科技蓝用于次级行动、边框高亮、AI 分析感。
- 不要全页面蓝色化，避免后台仪表盘感。

状态色：

- 成功绿只用于答对、完成、成长。
- 错误红只用于答错、高风险、纠错。
- 奖励金用于 XP、徽章、完成奖励。

掼蛋文化感：

- 通过牌面组件、红黑花色、牌桌位置和局势语言体现。
- 不通过赌场视觉、木纹牌桌、筹码和浮夸金属字体现。

## 3. 字体与信息层级

字体：

- 默认使用系统无衬线字体。
- 不使用花体、拟物游戏字体或过度赛博字体。
- 中文必须清晰，移动端 390px 下优先可读。

字号层级：

```txt
App Title: 24px / 32px / 700
Training Title: 22px / 30px / 800
Card Title: 18px / 26px / 700
Body: 14px / 22px / 500
Coach Text: 15px / 24px / 700
Meta / Badge: 12px / 18px / 700
Tiny Stat: 11px / 16px / 700
```

规则：

- 不使用随视口宽度缩放的字体。
- 字距保持默认，不使用负字距。
- 小卡片内部不用超大标题。
- 按钮文字必须短，优先 2 到 6 个汉字。
- 页面文案以短句为主，避免大段连续文字。

## 4. UI 组件规范

### 4.1 Card

用途：

- 今日训练任务。
- 残局挑战。
- 成长状态。
- 复盘总结。
- 路径节点。

样式：

```txt
border-radius: 20px - 24px
padding: 16px mobile / 20px desktop
background: Panel Surface
border: 1px solid Border Default
shadow: 0 16px 48px rgba(0, 0, 0, 0.22)
```

当前任务卡：

- 使用能量黄边框或顶部能量线。
- 可使用轻微内发光。
- 必须包含：训练主题、目标、奖励、主 CTA。

禁忌：

- 不做卡片套卡片。
- 不把所有页面区域都做成同等重量的卡片。
- 不在卡片里塞长文。

### 4.2 Button

主按钮：

- 用于“开始训练”“继续练习”“完成训练”。
- 背景使用 Primary Energy Yellow。
- 文案必须行动明确。

次按钮：

- 用于“回路径”“去复盘”“直接做残局”。
- 使用深色面板 + 科技蓝或默认边框。

尺寸：

```txt
height: 44px - 52px
border-radius: 16px
padding-x: 16px - 20px
font-size: 14px
font-weight: 700
```

状态：

- pressed: scale 0.98。
- disabled: opacity 0.45，不可点击。
- loading: 保留按钮宽度，避免布局跳动。

### 4.3 Progress Bar

用途：

- XP 能量槽。
- 7 天训练进度。
- 当前任务完成度。

样式：

- 背景为 Panel Soft。
- 进度填充使用 Energy Yellow 或 Tactical Green。
- 高度 8px - 10px。
- 圆角 full。
- label 显示在上方或左侧，不压在条内。

动效：

- V1 可使用 CSS/Framer Motion 轻微增长。
- 不做粒子、爆炸和阻塞动画。

### 4.4 Badge

用途：

- Day 1 / 7。
- +20 XP。
- 当前状态：待完成、已完成、错题。
- 能力标签：牌权、炸弹、配合。

样式：

```txt
border-radius: 999px
padding: 6px 10px
font-size: 12px
font-weight: 700
```

状态：

- 当前任务：能量黄背景或边框。
- 完成：成功绿。
- 风险：警告红。
- 普通标签：深色面板 + 次级文字。

### 4.5 Coach Bubble

用途：

- 今日推荐。
- 学习提示。
- 答题反馈。
- 错误总结。
- 下一步建议。

样式：

- 头像 + 气泡横向排列。
- 移动端头像 48px - 56px。
- 文案最多 2 到 3 行。
- 背景为 Panel Surface，不使用纯聊天气泡白底。
- 状态色只用于边框、小标签或头像状态，不大面积铺色。

状态：

- idle：普通边框。
- thinking：科技蓝边框或提示点。
- teaching：能量黄小标签。
- warning：警告红小边框，语气克制。
- celebrate：奖励金和成功绿点缀。

### 4.6 Training Card

用途：

- 首页首屏主模块。
- 每天只展示一个主训练任务。

必须包含：

- Day 编号。
- 今日主题。
- 一句训练目标。
- 奖励 XP。
- 预计耗时。
- 主 CTA。

视觉：

- 是首页最强卡片。
- 比普通卡片更有任务面板感。
- 允许使用顶部能量线、角标、轻微边框高亮。
- 不展示内部技术字段，例如 `lessonId`、`practiceId`。

## 5. AI Coach 视觉规范

AI Coach 是训练中枢，不是页面装饰。

出现位置：

- 首页：首屏今日任务前或与今日任务并列。
- Lesson：知识点重点提示处，inline 出现。
- Practice：用户选择后在反馈区出现，答题前不遮挡牌桌。
- Result：完成页顶部，给今日总结和明日建议。
- Profile：低频出现，给成长建议。

状态：

```txt
idle: 默认待机
thinking: 用户思考或分析中
teaching: 讲解知识点
warning: 纠错和风险提醒
celebrate: 完成训练和奖励
```

规则：

- V1 使用现有 `CoachAvatar` 和 `CoachBubble`。
- 头像可先用占位，但状态要清楚。
- 气泡不讲长文。
- 牌局页面中，牌桌和手牌优先级高于 Coach。
- 未来真实 AI 只能返回结构化短反馈，不直接输出长文本。

## 6. 游戏化成长规范

游戏化目标：

> 让用户感到自己每天都在变强，但不幼稚、不焦虑。

### 6.1 等级

等级展示：

- 首页必须可见。
- Profile 中作为成长档案核心。
- Result 页显示本次训练后的等级进度。

建议等级文案：

```txt
Lv1 新手上桌
Lv5 牌权入门
Lv10 配合玩家
Lv20 残局熟手
Lv30 控牌高手
Lv50 实战教练
```

### 6.2 XP

XP 是每日训练的即时奖励。

规则：

- 完成 Lesson 可给少量 XP。
- 完成 Daily Training 给主奖励。
- Result 页必须显示本次获得 XP。
- 首页展示距离下一级还差多少。

### 6.3 连续学习

Streak 用于留存，但不要制造压力。

表现：

- 使用“连续 X 天”。
- 可搭配能量点、火花或小光点。
- 断签时不做惩罚式红色警告。

### 6.4 徽章

徽章用于能力成就，不用于廉价装饰。

建议徽章：

- 牌权观察
- 炸弹克制
- 队友配合
- 防守拦截
- 残局收尾
- 复盘完成

视觉：

- 竞技勋章感。
- 深色底 + 能量边框。
- 小尺寸可识别。

### 6.5 任务完成反馈

完成训练后必须反馈：

- 今天学会了什么。
- 获得多少 XP。
- 当前等级进度。
- 明天练什么。

反馈应短、明确、有成长感。

## 7. 页面视觉方向

### 首页

目标：像训练大厅，不像课程网站。

首屏必须有：

- 今日训练目标。
- Ace / AI Coach 一句提醒。
- 主 CTA。
- XP 或等级状态。

避免：

- 大量功能入口。
- 展示 `lessonId`、`practiceId` 等技术字段。
- 把路径、专题、状态都做成同等权重。

### Lesson

目标：像一个训练步骤，不像文章详情。

重点：

- 一句口诀。
- 一张牌局图或牌面组件。
- 错误 / 正确判断。
- 完成后进入对应残局。

避免：

- 课程目录侧栏抢注意力。
- 占位图过强、技术感过重。
- 小练习只是展示不能交互。

### Practice

目标：像实战决策台，不像表单选择题。

重点：

- 当前局面。
- 牌桌和手牌。
- 清晰选项。
- 选择后即时 Coach 反馈。
- 复盘步骤。

避免：

- 选项和牌桌割裂。
- 反馈像普通提示卡。
- “完成今天训练”出现得太像普通按钮。

### Result

目标：像训练结算页，不像普通成功页。

重点：

- Coach 总结。
- XP 奖励。
- 等级进度。
- 明日训练。

避免：

- 只显示通用完成文案。
- 奖励弱、不像成长反馈。

### Profile

目标：像成长档案，不像设置页。

重点：

- 等级和 XP。
- 连续训练。
- 已完成训练。
- 错题和薄弱能力。
- 徽章和能力进度。

避免：

- 只显示课程 / 练习 / 收藏计数。
- 缺少下一步训练建议。

## 8. V1 实施边界

V1 做：

- 统一色彩 token。
- 统一卡片、按钮、进度条、徽章样式。
- 首页训练大厅化。
- Lesson / Practice / Result 的训练感升级。
- Coach 气泡状态化。
- Profile 成长档案化。

V1 不做：

- 真实 AI。
- 数据库。
- 图片生成。
- 复杂动画。
- 3D 角色。
- 扩课程。
- 付费和登录。

## 9. 视觉验收标准

每次 UI 升级前检查：

1. 是否像 AI 训练 App，而不是课程站。
2. 用户 5 秒内是否知道今天做什么。
3. 主 CTA 是否明确。
4. AI Coach 是否在引导训练，而不是装饰。
5. 是否有 XP / 等级 / 连续学习等成长反馈。
6. 牌局内容是否比装饰更清晰。
7. 390px 到 430px 是否可读、可点、不卡。
8. 是否没有新增真实 AI、数据库、图片生成和复杂动画。
