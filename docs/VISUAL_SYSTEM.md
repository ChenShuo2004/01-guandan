# 视觉系统规范

本文档定义掼蛋 AI 学习平台的基础视觉方向。V1 先保证移动端清晰、统一、可扩展，不追求复杂视觉。

## 1. 设计关键词

1. Mobile First
2. 图片优先
3. 深色背景
4. 暖黄色点缀
5. 卡片式布局
6. 大图片、小文字
7. 清晰层级
8. 轻量动效

参考方向：

1. Duolingo 的成长体系
2. Chess.com 的训练感
3. 小红书的图解内容
4. Notion 的知识组织

## 2. 色彩

建议基础色：

```txt
背景：#10131A
主卡片：#181C25
次级卡片：#202634
主色：#F6C65B
成功：#55D68A
错误：#FF6B6B
文字主色：#F8FAFC
文字次色：#A7B0C0
边框：#2A3140
```

使用规则：

1. 背景保持深色，降低学习时的视觉干扰。
2. 暖黄色用于主要按钮、路径进度和关键提示。
3. 成功和错误色只用于答题反馈。
4. 不要把页面做成单一黄色或单一深蓝主题。

## 3. 字体层级

```txt
页面标题：24px / 32px / 700
卡片标题：18px / 26px / 700
正文说明：14px / 22px / 500
教练短句：15px / 24px / 600
标签文字：12px / 18px / 600
```

规则：

1. 不使用随视口宽度变化的字体。
2. 字距保持默认，不使用负字距。
3. 小卡片内部不用超大标题。
4. 移动端优先保证文字不溢出、不重叠。

## 4. 布局

移动端优先范围：

```txt
主要适配：390px - 430px
最小可用：360px
桌面端：居中显示或扩展为多列
```

页面结构：

1. 顶部内容区
2. 主卡片区
3. 横向滚动专题区
4. 底部导航

组件尺寸：

1. 卡片圆角建议 16px。
2. 按钮高度建议 44px 到 52px。
3. 底部导航高度建议 64px 到 76px。
4. 内容左右间距建议 16px。

## 5. 卡片规则

卡片用于：

1. 课程入口
2. 残局入口
3. 专题 Banner
4. 学习路径节点
5. 答题选项

避免：

1. 卡片套卡片。
2. 页面所有区域都做成浮动卡片。
3. 卡片内部塞入长文章。

## 6. 图片规则

图片承担：

1. 课程知识图
2. 专题封面
3. 角色姿势
4. 残局氛围图

图片不承担：

1. 准确扑克牌牌面
2. 实时出牌交互
3. 可控牌局动画
4. 页面说明文字

扑克牌牌面必须由前端组件渲染。

## 7. V1 占位资源

第一阶段所有图片位置使用占位资源：

1. 渐变或纯色块
2. assetId 文案
3. 前端渲染的牌面
4. 简单图形符号

后续素材生成后，通过 Manifest 替换为真实资源。
