# 观察模式规则

`/practice/[practiceId]` 的记牌训练使用 `GameArena(observerMode)`。

## 行动规则

- 四个座位全部由 AI 自动出牌，包括底部的 `player` 座位。
- 用户不选择手牌、不点击出牌、不点击不出；用户只观察牌局并完成记牌测试。
- `player.kind = "human"` 只描述普通牌局模式下的角色身份；在 `observerMode` 中，行动权统一交给 AI 调度。
- 跳过按钮只跳过当前座位的 AI 等待，不跳过其他座位，也不改变牌局规则。

## 倒计时规则

- 当前 AI 回合开始时创建一个等待倒计时。
- 倒计时由 `GameArena` 的本地计时器每秒递减。
- 画面显示使用同一份本地倒计时，避免 reducer 更新和计时器不同步。
- 倒计时结束或点击“跳过 AI”后，调用 `runAIAction()` 推进当前座位。
- 观察暂停、发牌锁定、记牌测试和反馈阶段不会推进 AI 回合。

## 连续升级赛规则

- 记牌训练是一轮连续掼蛋升级赛，不是每手结束就重置训练。
- 双方初始级牌都是 `2`。
- 每手结束后，根据头游队伍和队友名次升级：双上 +3，队友三游 +2，队友末游 +1。
- 只有头游所在队升级，另一队级牌保持不变。
- 下一手重新发牌，但保留双方级牌、已完成手数、记牌检查点和训练统计。
- 当前手的打几使用上一手头游队伍升级后的级牌。
- 某队在 `A` 级牌再次获胜后，本轮结束并进入复盘报告；此时不再自动开始下一手。

## 记牌阶段推进

- 目标顺序固定为 `JOKER -> 当前级牌 -> A -> K -> Q -> J -> 10 ... 3 -> 2`。
- 记牌测试只暂停当前连续牌局，不重置双方级牌。
- 回答反馈确认后，如果当前手未结束，则继续当前牌局。
- 如果当前手已结束，则先完成结算和升级，再进入下一手或整轮报告。
