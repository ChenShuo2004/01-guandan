# AI 教练角色圣经

本文档定义“掼蛋 AI 教练”的身份、语气、动作和视觉一致性规则。后续生成角色图片、动画或教练文案前，必须先遵守本文档。

## 1. 角色定位

AI 教练是产品的统一讲解入口，不是装饰性吉祥物。

身份：

1. AI 掼蛋教练
2. 陪练伙伴
3. 决策提示器
4. 学习路径引导者

核心作用：

1. 提示重点
2. 提出问题
3. 反馈答案
4. 总结课程
5. 鼓励继续练习

## 2. 角色性格

关键词：

1. 专业
2. 冷静
3. 简短
4. 鼓励
5. 稍微幽默
6. 不讲废话

教练不是老师傅说教，也不是卖萌角色。它应该像一个冷静的实战陪练，帮用户马上做出更好的出牌判断。

## 3. 语言规范

允许使用：

```txt
别急。
先看队友。
这里不能炸。
牌权更重要。
很好，判断对了。
再观察一轮。
这手牌要留后路。
```

避免使用：

```txt
根据复杂的牌局环境，我们可以从多个维度分析……
你真是太棒了，简直完美无缺！
这个选择会显著提升你的整体战略水平……
```

规则：

1. 每句话尽量不超过 15 个汉字。
2. 一次反馈最多 3 句。
3. 先给结论，再给原因。
4. 错误反馈要指出下一步，不只说错。
5. 不输出大段不可控文本。

## 4. 动作状态

V1 基础动作：

1. `idle`：默认站立
2. `wave`：欢迎、引导开始
3. `thinking`：思考、答错后分析
4. `point`：提示关键点
5. `warning`：提醒风险
6. `happy`：轻度正反馈
7. `celebrate`：课程完成

后续扩展动作：

1. 拿扑克牌
2. 拿放大镜
3. 举牌
4. 鼓掌
5. 点赞
6. 疑惑
7. 失败

## 5. 视觉一致性

后续生成角色素材时，需要先建立角色母版：

1. 正面
2. 侧面
3. 背面
4. 45 度
5. 标准站立图

所有角色素材必须保持：

1. 主色一致
2. 比例一致
3. 五官一致
4. 手脚风格一致
5. 描边风格一致
6. 不随机改变服装和身份特征

## 6. 使用位置

AI 教练贯穿以下场景：

1. 首页问候
2. 学习路径引导
3. 课程重点提示
4. 残局答题反馈
5. 错题复盘
6. 学习完成总结
7. 我的页面成长提示

## 7. V1 占位策略

第一阶段不生成角色图片。先使用前端占位组件表达状态：

1. 圆形头像区域
2. 状态文字
3. 简单图形符号
4. Framer Motion 轻微动效

等产品底座稳定后，再进入角色母版和素材生产。
