# 05. Visual Color System

> AI 掼蛋训练空间视觉色彩系统规范  
> Version: V1.0  
> Scope: Training Arena / Ace AI Coach / Skill Assessment / Ability Profile / Training Recommendation

---

## 1. 品牌视觉定位

AI 掼蛋训练空间不是传统棋牌 App，也不是课程网站，也不是数值成长游戏。

它的核心视觉定位是：

> 一个由 Ace AI 教练陪伴用户完成能力测评、理解当前水平、获得训练诊断，并进入下一步专项训练的掼蛋训练空间。

用户打开产品时，第一感受应该是：

- 我可以快速知道自己现在是什么水平
- Ace 会告诉我为什么是这个水平
- 系统能指出我的强项和短板
- 我知道下一步该练什么
- 掼蛋能力可以被测试、被诊断、被训练、被复测

### 产品视觉关键词

| 关键词 | 含义 |
|---|---|
| 智能 | AI 分析用户答题表现，形成能力诊断 |
| 年轻 | 轻量、有节奏、低压力、有陪伴 |
| 专业 | 像训练系统，而不是娱乐大厅 |
| 清晰 | 当前水平、能力强弱、下一步建议一眼可见 |
| 科技 | 深色空间、蓝色分析光、玻璃信息层 |
| 陪伴 | Ace 用黄色提示关键判断和行动建议 |

### 与普通棋牌产品的区别

普通棋牌产品强调：

- 开局
- 房间
- 输赢
- 虚拟货币
- 排行榜
- 娱乐刺激
- 传统牌桌氛围

AI 掼蛋训练空间强调：

- 测试
- 判断
- 诊断
- 画像
- 专项训练
- 复测提升
- Ace 教练陪伴

因此，视觉上不使用传统棋牌的红金、木纹、赌场、房间大厅风格，也不使用廉价手游式成长反馈。

产品应该更像：

```txt
AI 能力测评舱
Ace 教练诊断台
掼蛋专项训练场
个人能力画像系统
```

### 与 Ace 教练 IP 的关系

Ace 不是装饰角色，而是用户理解诊断结果的教练入口。

蓝色代表 AI 分析、能力诊断和训练路径。  
黄色代表 Ace 教练判断、关键建议和下一步行动提示。  
白色代表 AI 信息清晰度、解释结构和阅读秩序。  
绿色代表已掌握能力。  
橙色代表待提升能力。  
深色背景代表沉浸式 AI 训练空间。

Ace 的黄色必须像蓝色训练空间中的一束教练提示光，而不是独立漂浮的卡通贴纸。

## 3. 推荐色彩比例

| 色彩系统 | 占比 | 说明 |
|---|---:|---|
| 生命蓝 | 50% | 构建 AI 分析、诊断路径和训练空间识别 |
| 深色背景 | 25% | 提供沉浸、专业、安静的训练环境 |
| 科技白 | 15% | 保证诊断信息、解释文字和牌局内容清晰 |
| Ace 黄色 | 6% | 只用于 Ace 判断、关键建议和行动提示 |
| 绿色与橙色 | 4% | 只用于掌握状态和待提升状态 |

### 分配原因

蓝色必须是第一视觉记忆点，因为产品本质是 AI 分析与能力训练系统。  
深色背景负责空间感，但不能压过牌面和诊断信息。  
白色负责清晰表达，让用户快速理解结果。  
黄色必须少而准，用来承载 Ace 的教练判断。  
绿色和橙色只在能力画像和反馈中出现，避免界面变成五颜六色的状态面板。

视觉层级应遵循：

```txt
蓝色建立系统
白色解释信息
黄色给出教练判断
绿色确认已掌握
橙色指出待提升
```

## 5. 光效系统

未来科技感来自克制的光效，而不是堆叠特效。

原则：

> 光效必须服务信息层级，帮助用户理解当前状态，不制造视觉噪音。

### 5.1 Glow 光晕

使用场景：

- 当前测试入口
- Ace 头像状态
- 当前能力诊断结论
- Skill Assessment Bar 当前段
- 正确或错误反馈

规则：

- AI 分析使用蓝色 glow
- Ace 建议使用黄色 glow
- 已掌握使用绿色 glow
- 待提升使用橙色 glow
- 光晕持续时间短，强度低

禁止：

- 页面所有卡片同时发光
- 大面积霓虹边框
- 高频闪烁
- 光效遮挡文字和牌面

---

### 5.2 Insight Line 洞察线

使用场景：

- 从测试结果连接到能力画像
- 从能力短板连接到推荐训练
- Ace 指向关键建议
- 训练路径节点之间的引导

规则：

- 线条细、轻、连续
- 蓝色表示系统分析关系
- 黄色表示 Ace 给出的关键建议
- 橙色只用于待提升能力连接

禁止：

- 不做复杂电路板背景
- 不让线条变成装饰噪音
- 不覆盖牌面、按钮和主要文字

---

### 5.3 Glass 透明玻璃效果

使用场景：

- 测评卡片
- 诊断卡片
- Ace Coach Bubble
- Ability Profile Card
- Training Recommendation Card
- 底部导航

规则：

- 背景使用 `#FFFFFF0F` 到 `#FFFFFF1F`
- 边框使用 `#FFFFFF26` 到 `#FFFFFF4D`
- 保持文字对比度
- 玻璃层只承载一个信息主题

禁止：

- 不在低端设备上依赖复杂模糊
- 不用玻璃效果承载大段文字
- 不让透明层影响牌面识别

---

### 5.4 Particle 粒子效果

使用场景：

- 测试完成后的诊断生成瞬间
- 能力画像生成瞬间
- Ace 给出关键建议时的轻量提示
- 专项训练完成后的掌握确认

规则：

- 粒子数量少
- 持续时间短
- 蓝色用于系统分析
- 黄色用于 Ace 建议
- 绿色用于已掌握确认

禁止：

- 不作为常驻背景
- 不做爆炸式效果
- 不影响按钮点击和阅读

## 6. UI 组件颜色规范

### 6.1 Buttons

#### Primary Button

用途：

- 开始测评
- 查看能力画像
- 开始推荐训练
- 提交判断
- 再次测试

颜色：

- 默认：`Primary/Blue-500`
- Active：`Primary/Blue-600`
- Disabled：`Neutral/White-30`
- Text：`Neutral/White-100`

规则：

- 一个屏幕最多一个 Primary Button
- 主按钮始终指向当前最重要行动
- 可使用轻微蓝色 glow 强化行动感

禁止：

- 不用黄色做普通主按钮
- 不用红色、紫色做主行动
- 不多个 Primary Button 并列竞争

#### Secondary Button

用途：

- 查看解释
- 换一道题
- 稍后训练
- 查看详情

颜色：

- 背景：`Neutral/White-12`
- 边框：`Neutral/White-30`
- Text：`Neutral/White-80`

规则：

- 保持轻量
- 不抢主 CTA
- 可搭配玻璃效果

---

### 6.2 Skill Assessment Bar

定义：

Skill Assessment Bar 用来展示用户当前能力测评结果，不显示数值积累。

内容结构：

```txt
当前水平
测评可信度
强项数量
待提升能力
推荐训练方向
```

颜色：

- Track：`Neutral/White-12`
- 当前水平段：`Primary/Blue-500`
- 已掌握能力：`Ability/Mastered-500`
- 待提升能力：`Ability/Improve-500`
- Ace 建议提示点：`Accent/Ace-500`

使用规则：

- 用于测评结果页和首页摘要
- 展示当前水平，而不是长期积分
- 重点显示用户下一步该练什么

禁止：

- 不做经验槽视觉
- 不显示刷分式进度
- 不制造数值压力

---

### 6.3 Ability Profile Card

定义：

Ability Profile Card 是用户当前掼蛋能力画像的核心展示组件。

内容结构：

```txt
当前水平
能力维度
已掌握能力
待提升能力
Ace 诊断
下一步训练建议
```

颜色：

- 背景：`Background/Space-800`
- 标题：`Neutral/White-100`
- 系统分析：`Primary/Blue-500`
- Ace 关键判断：`Accent/Ace-500`
- 已掌握：`Ability/Mastered-500`
- 待提升：`Ability/Improve-500`

推荐能力维度：

- 牌权判断
- 炸弹时机
- 贡牌理解
- 队友配合
- 残局收尾
- 风险控制
- 过牌判断

禁止：

- 不做个人资料卡风格
- 不堆砌无意义数字
- 不用多彩徽章破坏专业感

---

### 6.4 Training Recommendation Card

定义：

Training Recommendation Card 用来承接测评结果，把能力短板转化为下一步训练。

内容结构：

```txt
推荐训练主题
对应短板
预计用时
训练目标
Ace 一句话建议
开始训练
```

颜色：

- 背景：深色玻璃
- 推荐依据：`Primary/Blue-400`
- Ace 建议：`Accent/Ace-500`
- 待提升能力标签：`Ability/Improve-500`
- 行动按钮：`Primary/Blue-500`

使用规则：

- 每张卡只推荐一个训练方向
- 强调为什么推荐
- 强调训练后能改善什么
- CTA 指向专项训练

禁止：

- 不做任务结算卡
- 不展示虚拟货币、抽卡感元素
- 不同时塞入多个训练目标

---

### 6.5 Assessment Result Card

定义：

Assessment Result Card 用于用户完成测试后的即时结果展示。

内容结构：

```txt
测评完成
当前水平
主要强项
主要短板
Ace 诊断结论
下一步建议
```

颜色：

- 当前水平：`Primary/Blue-500`
- Ace 诊断结论：`Accent/Ace-500`
- 强项：`Ability/Mastered-500`
- 短板：`Ability/Improve-500`
- 文字：`Neutral/White-100`

规则：

- 先给结论，再给原因
- 结论必须短
- 每次只突出一个最重要短板

### 6.6 Feedback

#### 正确反馈

颜色：

- 主色：`Ability/Mastered-500`
- 背景：`Ability/Mastered-900`
- 文字：`Neutral/White-100`

语气：

- 清楚确认
- 指出判断依据
- 说明该能力点已表现稳定

#### 错误反馈

颜色：

- 主色：`Ability/Improve-500`
- 背景：`Ability/Improve-900`
- 文字：`Neutral/White-100`

语气：

- 不惩罚
- 指出误区
- 给出下一次判断方法

#### 诊断反馈

颜色：

- 系统分析：`Primary/Blue-500`
- Ace 结论：`Accent/Ace-500`
- 文字：`Neutral/White-100`

语气：

- 像教练总结
- 不像考试判分
- 重点是下一步怎么变好

## 7. Ace 角色视觉融合

Ace 是蓝色训练空间中的黄色判断光源。

### 7.1 角色背景光

默认状态：

- 背景光：蓝色低透明圆形 glow
- 边缘：轻微 Ace 黄色
- 角色与系统环境保持融合

测评状态：

- 蓝色分析光增强
- Ace 黄色保持低强度
- 表达系统正在观察和分析

诊断状态：

- 黄色成为关键提示光
- 蓝色保持为环境背景
- Ace 给出一句明确判断

教学状态：

- 蓝色为主
- 黄色只用于重点提醒
- 保持专业教练感

纠偏状态：

- 橙色只作为局部提示
- Ace 主体仍保持黄色识别
- 不制造失败感

### 7.2 头像边框

| 状态 | 边框颜色 |
|---|---|
| 默认 | `Primary/Blue-400` |
| 测评中 | `Primary/Blue-500` + 轻微呼吸光 |
| 给出建议 | `Accent/Ace-500` |
| 已掌握确认 | `Ability/Mastered-500` 小范围点亮 |
| 待提升提醒 | `Ability/Improve-500` 小范围提示 |

规则：

- Ace 始终与蓝色系统连接
- 黄色只在关键判断和建议时增强
- 橙色提醒不能覆盖 Ace 的品牌识别

### 7.3 Coach Bubble 色彩

Coach Bubble 分三类：

| 类型 | 主色 | 使用场景 |
|---|---|---|
| 分析中 | 蓝色 | 系统正在判断表现 |
| 关键建议 | 黄色 | Ace 给出最重要的一句话 |
| 纠偏提醒 | 橙色 | 用户出现明显短板 |

原则：

- 一条 Coach Bubble 只表达一个重点
- 黄色句子必须短
- 不让 Ace 讲大段分析

## 8. 页面视觉应用

### 8.1 首页 Training Arena

目标：

用户 5 秒内知道自己应该先测试、继续训练，还是查看当前能力画像。

颜色结构：

- 背景：深海科技渐变
- 主入口：AI 分析渐变
- Ace：黄色轻光，作为教练引导
- 当前水平摘要：蓝色系统卡片
- 下一步建议：Ace 黄色高亮
- 推荐训练：深色玻璃卡片

视觉重点顺序：

1. 当前状态：未测评 / 已测评 / 建议复测
2. 主行动：开始测评 / 查看画像 / 开始推荐训练
3. Ace 关键建议
4. 当前能力摘要
5. 专项训练入口

禁止：

- 首页变成功能入口集合
- 首页变成课程目录
- 多个模块争夺主 CTA
- 用成长数值替代能力诊断

---

### 8.2 能力测评页面

目标：

让用户专注完成判断题，系统收集能力信号。

颜色结构：

- 背景：`Background/Space-900`
- 题目区域：深色分析面板
- 当前题进度：生命蓝
- 选项：科技白文字 + 玻璃底
- 选中态：生命蓝描边
- Ace 提示：低强度黄色，不泄露答案

视觉原则：

- 牌面识别第一
- 题目判断第二
- Ace 陪伴第三
- 不用夸张倒计时制造压力

---

### 8.3 测评结果页面

目标：

让用户清楚理解当前水平、强项、短板和下一步建议。

颜色结构：

- 当前水平：生命蓝
- Ace 诊断：Ace 黄色
- 已掌握能力：训练绿
- 待提升能力：纠偏橙
- 推荐训练：蓝色主按钮

视觉重点顺序：

1. 当前水平
2. Ace 一句话诊断
3. 强项和短板
4. 推荐训练
5. 查看完整能力画像

禁止：

- 不用考试排名式压迫感
- 不展示复杂分数墙
- 不把结果做成游戏结算页

---

### 8.4 学习页面

目标：

一个页面只讲一个知识点，服务后续训练。

颜色结构：

- 背景：`Background/Space-900`
- 标题：`Neutral/White-100`
- 核心判断：`Primary/Blue-500`
- Ace 重点提醒：`Accent/Ace-500`
- 错误示范：`Ability/Improve-500`
- 正确示范：`Ability/Mastered-500`

视觉原则：

- 图解优先
- 文案短
- 一页只讲一个判断
- 底部 CTA 指向训练或复测

---

### 8.5 残局训练页面

目标：

让用户在接近实战的情境里练判断，并获得针对性反馈。

颜色结构：

- 背景：深色训练桌面
- 牌面：高对比白色牌面
- 可选牌：蓝色描边
- 已选择：蓝色高亮
- 正确反馈：训练绿
- 错误反馈：纠偏橙
- Ace 诊断：黄色重点句

视觉原则：

- 牌面识别优先于所有视觉效果
- 答题前不暴露反馈色
- 答题后只突出一个关键判断

---

### 8.6 能力画像页面

目标：

让用户看到自己当前掼蛋能力结构，而不是一串抽象分数。

颜色结构：

- 背景：深海科技渐变
- 能力雷达：蓝色系统线
- 已掌握：绿色
- 待提升：橙色
- Ace 结论：黄色
- 推荐训练：蓝色主 CTA

内容结构：

```txt
当前水平
能力雷达
强项
短板
Ace 诊断
下一步训练
复测入口
```

视觉原则：

- 当前水平要显眼
- 短板不超过 3 个
- 下一步建议必须明确
- 页面不追求炫酷图表，追求行动清晰

## 9. 图片和动画视觉规范

未来所有 AI 生成图片、角色动画、UI 动画必须遵循统一视觉基因，避免不同时间生成的素材风格分裂。

### 9.1 AI 生成图片

背景规则：

- 深色蓝黑训练空间
- 柔和蓝色环境光
- 少量黄色教练提示光
- 不使用真实赌场、棋牌室、木桌大厅

光照规则：

- 主光：蓝色科技光
- 辅光：白色清晰光
- 提示光：Ace 黄色
- 状态光：绿色或橙色仅局部出现

色彩规则：

- 主体不超过三种核心色
- 蓝色占主导
- 黄色只作为关键提示
- 白色保证清晰
- 绿色和橙色只表达能力状态

材质规则：

- 玻璃
- 半透明界面
- 柔和金属
- 数字训练空间
- 干净牌面

禁止：

- 传统棋牌馆
- 赌场筹码
- 复杂机甲
- 过度赛博朋克
- 低质手游按钮风
- AI 图片生成准确牌面

---

### 9.2 角色动画

Ace 动画风格：

- 轻量
- 温暖
- 克制
- 像教练，不像娱乐吉祥物

状态动画：

| 状态 | 动画方向 |
|---|---|
| 欢迎 | 轻微呼吸光 |
| 测评中 | 蓝色扫描光 |
| 思考中 | 蓝白微光循环 |
| 给出建议 | 黄色重点光 |
| 确认掌握 | 绿色轻点亮 |
| 纠偏提醒 | 橙色小提示 |

禁止：

- 高频抖动
- 大幅跳跃
- 夸张表情
- 长时间循环干扰训练

---

### 9.3 UI 动画

动画原则：

- 反馈明确
- 时间短
- 不抢内容
- 不影响性能

推荐动画：

| 动作 | 时长 |
|---|---:|
| Button press | 80-120ms |
| Card enter | 160-240ms |
| Feedback reveal | 200-300ms |
| Assessment generated | 500-800ms |
| Ability profile update | 600-900ms |

颜色联动：

- 开始测评：蓝色分析流
- 判断正确：绿色确认
- 判断错误：橙色提醒
- Ace 建议：黄色点亮
- 画像更新：蓝色到绿色或橙色的状态变化

---

## 10. 禁止事项

明确禁止：

- 不要大量紫色电竞风
- 不要纯黑背景
- 不要高饱和多颜色混用
- 不要每个模块不同主题
- 不要传统棋牌红金配色
- 不要赌场、筹码、商城式视觉
- 不要廉价手游式弹窗反馈
- 不要所有卡片都发光
- 不要让 Ace 黄色变成普通按钮色
- 不要让错误反馈像惩罚
- 不要破坏 Ace 品牌识别
- 不要用 AI 图片生成准确牌面
- 不要牺牲牌面识别换取视觉炫技
- 不要把首页做成课程网站或功能大厅
- 不要把能力测评做成考试排名压力
- 不要用抽象数值替代清晰训练建议

## 11. V1 / V2 / V3 演进

### V1：静态测评与诊断阶段

目标：

建立稳定、清晰、可上线的能力测评视觉系统。

包含：

- 蓝白主系统
- 深色训练空间背景
- Ace 静态教练形象
- Skill Assessment Bar
- Ability Profile Card
- Training Recommendation Card
- 基础正确与错误反馈
- 规则驱动 Ace 诊断文案

视觉重点：

- 清晰
- 统一
- 移动端可读
- 测试到建议闭环成立

不做：

- 复杂角色动画
- 大量粒子
- 动态环境
- 真实 AI 接口视觉状态
- 游戏化数值成长体系

---

### V2：专项训练与复测阶段

目标：

让用户感到每一次训练都在改善某个具体能力点。

增加：

- Ace 状态动画
- 能力画像变化反馈
- 专项训练推荐
- 复测入口
- 弱项纠偏视觉
- 强项稳定确认
- 更清晰的测试历史对比

视觉重点：

- 教练陪伴
- 能力变化
- 训练闭环
- 下一步明确

注意：

- 动效不能影响训练效率
- 诊断不能变成复杂报表
- Ace 不能抢走牌局判断主体

---

### V3：AI 个性化训练空间阶段

目标：

形成完整的个性化 AI 掼蛋训练空间。

增加：

- 动态 Training Arena
- Ace 实时诊断状态
- 个性化能力画像
- 自动生成训练建议
- 多轮测试对比
- 训练结果可视化
- 结构化 AI 分析结果视觉化

视觉重点：

- 用户感觉自己进入了一个真正的 AI 能力训练空间
- Ace 是长期陪伴的数字教练
- 每次测试和训练都能沉淀为清晰的能力判断

最终方向：

```txt
蓝色承载 AI 分析
白色承载清晰解释
黄色承载 Ace 建议
绿色确认已掌握
橙色指出待提升
```

产品体验闭环：

```txt
测试
-> 能力画像
-> 专项训练
-> 再次测试
-> 能力提升
```

这套视觉系统的目标不是让用户觉得自己在玩一个数值成长游戏，而是让用户相信：

> 我的掼蛋水平可以被看见，可以被解释，也可以被训练。
