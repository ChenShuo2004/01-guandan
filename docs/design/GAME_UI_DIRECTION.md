# Game UI Direction

> 当前方向：AI 掼蛋训练空间  
> 核心体验：测试 -> 能力画像 -> 专项训练 -> 再次测试 -> 能力提升

## 1. 产品视觉定位

产品目标从“学习工具”升级为“AI 掼蛋训练空间”。

它不是经验成长游戏，也不是传统棋牌大厅，而是一个帮助用户判断当前掼蛋水平、看清能力短板、进入下一步训练的 AI 教练空间。

视觉关键词：

- AI 分析
- 能力测评
- 训练诊断
- 专项训练
- 科技空间
- 清晰行动
- Ace 陪伴

产品气质：

- 像进入一个专属训练舱，而不是打开课程列表。
- 像使用一个专业能力诊断工具，而不是玩数值成长游戏。
- 像有教练在场边陪你判断，而不是只有题库和答案。
- 像科技训练系统一样清楚、利落、可控。

用户进入时的第一感受：

```txt
我能知道自己当前水平。
Ace 会告诉我问题在哪里。
系统会推荐下一步训练。
我可以通过复测看到能力提升。
```

与普通棋牌 App 的区别：

- 普通棋牌 App 重点是开局、匹配、输赢。
- 本产品重点是测试、诊断、训练和复测。
- 普通课程 App 重点是目录和文章。
- 本产品重点是能力画像、专项训练和下一步建议。

视觉上要避免：

- 传统棋牌室的厚重木纹和赌场感。
- 纯知识付费课程列表。
- 大段文章站布局。
- 廉价手游式数值成长反馈。
- 过度二次元或儿童化游戏风格。

## 2. 首页视觉设计

首页应像 AI Training Arena，而不是课程列表或功能大厅。

首页信息优先级：

1. 当前测评状态
2. Ace 教练关键建议
3. 当前水平摘要
4. 推荐专项训练
5. 学习路径和复测入口

首页结构建议：

```txt
AI Training Arena
├── Ace 今日判断
├── 当前水平摘要
├── Skill Assessment Bar
├── Training Recommendation Card
├── 快速入口
│   ├── 开始测评
│   ├── 推荐训练
│   └── 再次测试
└── Ability Profile 摘要
```

AI 教练入口：

- Ace 应成为首屏强识别角色。
- 不做大面积营销 Hero。
- Ace 旁边只展示一句当前最重要建议。
- 入口像“教练诊断台”或“训练导航台”。

今日训练建议：

- 使用 Training Recommendation Card，而不是任务卡或课程卡。
- 明确显示推荐原因、预计时间、训练目标。
- 视觉像专业训练计划，而不是日常任务清单。

示例：

```txt
Ace 建议
先练「炸弹时机判断」
原因：你的测试中 3 次过早使用炸弹
```

当前水平：

- 首页必须可见当前能力水平。
- 当前水平来自测试结果，而不是长期数值累计。
- 重点展示“你现在是什么水平”和“下一步该练什么”。

训练入口：

- 残局训练：主训练入口。
- 学习路径：补齐判断方法。
- 再次测试：验证训练是否有效。
- 每个入口都应有明确状态：建议训练、已掌握、待提升。

## 3. 能力测评系统视觉

能力测评系统是产品的核心，不是个人资料页的附属信息。

当前水平：

- 使用清晰文字表达，例如：基础入门、稳定判断、进阶控牌、协同提升。
- 当前水平必须来自测试表现。
- 首页和能力画像页面都应展示。

Skill Assessment Bar：

- 用于展示当前测评结果。
- 表达用户在几个关键能力维度上的状态。
- 不做数值槽，不制造刷进度感。

能力画像：

- 展示用户的强项、短板和训练建议。
- 强项使用绿色。
- 短板使用橙色。
- Ace 的关键判断使用黄色。

训练诊断：

- 每次测试结束后给出一条最重要诊断。
- 诊断结构：当前水平、主要问题、下一步训练。
- 不堆砌复杂数据，避免用户看完不知道做什么。

复测：

- 复测用于验证专项训练是否有效。
- 复测结果应展示能力变化，而不是单次分数刺激。
- 变化反馈要轻，不做结算页。

能力测评参考原则：

- 当前水平明确。
- 强项和短板可见。
- 下一步训练清楚。
- Ace 解释要短。
- 复测体现能力变化。

## 4. AI 教练 Ace 视觉融合

Ace 是训练空间的核心角色，不是悬浮装饰。

Ace 如何成为教练角色：

- 首页：当前水平解释者。
- 测评页：陪伴用户完成判断。
- 结果页：能力诊断教练。
- 残局页：场边陪练。
- 复盘页：战术分析师。
- 能力画像页：下一步训练顾问。

欢迎状态：

- V1 使用静态欢迎姿态。
- V2 可加入轻微呼吸光或点头动作。
- 动作持续时间短，不占用操作节奏。

训练引导：

- Ace 给出下一步训练建议。
- Ace 指向当前推荐训练卡。
- Ace 的提示必须和能力短板绑定。

反馈状态：

- 答对时 Ace 使用确认状态。
- 答错时 Ace 使用纠偏状态。
- 测试完成时 Ace 给出诊断状态。
- 反馈要像教练提醒，不像游戏庆祝。

视觉融合规则：

- Ace 黄色代表关键建议。
- 系统蓝代表 AI 分析。
- 绿色代表已掌握能力。
- 橙色代表待提升能力。
- Ace 不应遮挡牌桌和测评信息。

## 5. 训练场概念

未来首页概念：AI Training Arena。

这是用户每天进入的训练空间，包含测评、画像、训练和教练引导。

核心模块：

当前测评：

- 展示用户是否已经完成测试。
- 如果未测评，主行动是“开始测评”。
- 如果已测评，主行动是“开始推荐训练”。

能力画像：

- 展示当前水平、已掌握能力、待提升能力。
- 作为用户理解自己水平的核心模块。
- 不做复杂个人资料页。

专项训练：

- 产品的核心训练入口。
- 每个训练都对应一个能力短板。
- 可显示难度、预计时间、训练目标和当前状态。

学习路径：

- 不展示为文章目录。
- 展示为能力路径。
- 每个节点是一个判断能力点。

复测入口：

- 用于验证训练效果。
- 视觉上应连接“测评”和“训练”，形成闭环。
- 不作为压力来源。

训练场的视觉语言：

- 诊断面板
- 能力雷达
- 训练路径
- 测评条
- 战术面板
- 轻量网格
- 牌桌焦点

## 6. 色彩系统

色彩目标：AI 训练空间 + 专业诊断感。

主背景：

- 深色科技背景或深蓝黑背景。
- 可使用微弱网格、噪点或光带。
- 不使用厚重棋牌室木色。
- 不使用纯黑，避免压抑。

科技蓝：

- 用于导航、边框、次级按钮、信息面板。
- 表达 AI 分析、能力诊断和训练路径。
- 是产品第一视觉识别色。

Ace 黄色：

- 用于 Ace、关键建议、当前推荐训练。
- 表达教练判断和下一步行动。
- 要控制面积，避免虚拟货币或商城感。

掌握绿：

- 用于答对、已掌握能力、稳定表现。
- 只在反馈和能力画像中出现。
- 不作为大面积主色。

纠偏橙：

- 用于答错、风险判断、待提升能力。
- 必须克制使用。
- 不做大面积警报，避免压迫。

建议色彩角色：

```txt
Background: dark navy / graphite
Primary System: analysis blue
Coach Accent: Ace yellow
Mastered: training green
Improvement: correction orange
Surface: dark panel / translucent card
Text: soft white / muted blue-gray
```

## 7. UI 组件风格

按钮：

- 主按钮指向当前最重要行动。
- 使用科技蓝。
- 文案短：开始测评、查看画像、开始训练、再次测试。
- 不使用过多渐变。
- 点击反馈轻微缩放。

卡片：

- 卡片像训练诊断面板。
- 边框可有轻微蓝色高亮线。
- 圆角保持克制，不要过度可爱。
- 信息层级清楚：结论、原因、建议、行动。

Skill Assessment Bar：

- 展示当前测评状态。
- 可分段显示不同能力维度。
- 蓝色代表系统分析，绿/橙代表能力状态。
- 不做经验槽视觉。

Ability Profile Card：

- 展示当前水平、强项、短板、Ace 诊断。
- 强项用绿色，短板用橙色。
- Ace 关键建议用黄色。
- 必须直接导向下一步训练。

Training Recommendation Card：

- 包含推荐训练主题、对应短板、预计时间、训练目标。
- 当前推荐训练视觉最强。
- 不展示虚拟收益。
- 不做任务结算视觉。

导航：

- 保持移动端底部导航。
- 当前页面高亮可加入蓝色光点。
- 不做复杂菜单。

牌桌组件：

- 牌桌永远是训练页焦点。
- 背景可加入战术面板感。
- 手牌、选项和反馈区必须清晰可读。

## 8. V1 / V2 / V3 路线

V1：静态测评与诊断。

- 首页从课程列表升级为训练空间。
- 当前测评状态、Ace 建议、推荐训练优先展示。
- Ace 作为首页教练和训练反馈角色。
- 使用静态图、气泡、测评条、诊断卡。
- 不做复杂动画，不做 3D。

V2：专项训练与复测反馈。

- Ace 加入轻动作。
- 能力画像加入变化反馈。
- 答对、答错、完成训练加入微反馈。
- 学习路径升级为能力路径。
- 残局训练加入专项能力状态。

V3：AI 个性化训练空间。

- 首页成为个性化 AI Training Arena。
- Ace 根据用户短板推荐训练。
- 训练内容动态生成。
- 复盘摘要和错题复训自动组织。
- 可引入更强沉浸感，但仍以牌局清晰为核心。

## 视觉验收标准

每次 UI 升级前检查：

1. 是否像训练空间，而不是文章目录。
2. 是否能一眼看到当前测评状态。
3. 是否能一眼看到当前水平和短板。
4. 是否保留 Ace 的角色识别。
5. 是否突出牌局训练，而不是装饰背景。
6. 是否移动端 390px 到 430px 可读。
7. 是否没有过度动画和复杂特效。
8. 是否让用户知道下一步该训练什么。
