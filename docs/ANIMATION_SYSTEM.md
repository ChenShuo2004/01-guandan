# 动画系统规范

本文档定义掼蛋 AI 学习平台的动效边界。V1 只做必要微动画，不做复杂牌局时间轴。

## 1. 动效原则

1. 动效服务理解，不服务炫技。
2. 动效必须轻、快、可控。
3. 不影响阅读和答题。
4. 不为了动画增加复杂依赖。
5. 移动端性能优先。

## 2. V1 使用范围

V1 使用 Framer Motion 处理：

1. 页面淡入
2. 卡片上移
3. 按钮点击反馈
4. 答题正确反馈
5. 答题错误轻微震动
6. 进度条增长
7. AI 教练轻微状态切换

暂时不做：

1. GSAP 复杂时间轴
2. 多张牌连续发牌
3. 炸弹特效
4. Lottie 角色循环动作
5. 自动生成动画素材

## 3. 动效分类

### 3.1 页面微交互

工具：Framer Motion

场景：

1. 页面进入
2. 卡片出现
3. 底部导航切换
4. 弹层出现

### 3.2 轻量牌移动

工具：Framer Motion

场景：

1. 单张牌选中
2. 手牌展开
3. 简单出牌提示

### 3.3 复杂牌局时间轴

工具：GSAP

后续场景：

1. 连续发牌
2. 多牌组合移动
3. 炸弹表现
4. 残局复盘

V1 只预留，不实现。

### 3.4 角色循环动作

工具：Lottie / SVG

后续场景：

1. 挥手
2. 点头
3. 思考
4. 庆祝

V1 只使用占位状态。

## 4. 动效参数建议

```txt
页面进入：duration 0.2s - 0.35s
卡片出现：duration 0.18s - 0.25s
按钮反馈：scale 0.98
答错震动：x [-4, 4, -2, 0]
进度增长：duration 0.35s - 0.6s
```

规则：

1. 不使用过长动画。
2. 同屏动效数量要少。
3. 答题反馈优先明确，不要过度装饰。

## 5. 和素材系统的关系

所有动画素材后续必须进入：

```txt
assets/manifests/animation-manifest.json
public/animations/
```

页面引用动画时使用 `animationId`，不要直接写死文件路径。

## 6. 验收标准

1. 手机端不卡顿。
2. 动画不遮挡文字。
3. 动画不改变核心布局尺寸。
4. 用户能快速完成学习和答题。
5. 没有复杂动画时，页面仍然完整可用。
