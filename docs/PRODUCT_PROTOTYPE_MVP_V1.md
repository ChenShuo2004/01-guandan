# 掼蛋 AI 教练 MVP 产品原型文档 V1.0

版本：V1.0  
产品名：掼蛋 AI 教练  
技术栈：Next.js + React + TypeScript + Tailwind CSS + Framer Motion  
产品目标：让用户 30 秒找到答案，1 分钟理解技巧，下一局马上能用。

## 1. 产品定位

掼蛋 AI 教练不是文章站、视频课或电子书，而是一个移动端优先的掼蛋训练 App。

核心体验：

1. AI 教练陪练
2. 图片和牌局图讲解
3. 一分钟知识卡片
4. 残局选择训练
5. 学习路径升级
6. 数据驱动扩展课程

V1 的目标不是做全，而是做出一个用户一打开就能学、能练、能感到进步的训练闭环。

## 2. V1 用户画像

### 2.1 新手用户

状态：

- 不熟规则
- 不知道牌型
- 不知道为什么输

核心需求：

- 快速入门
- 看懂牌局
- 少犯低级错误

首页推荐：

- Lv1 基础规则
- Lv2 牌型识别
- 今日新手题

### 2.2 中级用户

状态：

- 会打
- 经常凭感觉出牌
- 不知道什么时候炸、什么时候忍

核心需求：

- 学会判断局势
- 提升配合
- 减少乱炸、乱顶、乱拆牌

首页推荐：

- 炸弹专题
- 主攻打法
- 助攻打法
- 每日残局

### 2.3 高级用户

状态：

- 已有经验
- 想提高胜率和稳定性

核心需求：

- 残局推演
- 牌权控制
- 队友配合
- 心理博弈

首页推荐：

- 高阶残局
- 控牌专题
- AI 分析入口预告

## 4. 核心用户路径

### 4.1 新用户第一次进入

路径：

首页 → AI 教练问候 → 选择水平 → 推荐学习路径 → 学完第一课 → 做一道练习 → 获得经验

目标：

让用户在 3 分钟内完成一次完整正反馈。

### 4.2 老用户继续学习

路径：

首页 → 继续学习 → 当前课程 → 下一题 → 获得经验 → 解锁下一课

目标：

让用户不需要重新找内容。

### 4.3 残局训练路径

路径：

练习 → 今日残局 → 看牌局 → 选择 A/B/C → AI 教练反馈 → 正确动画 → 收藏或下一题

目标：

让用户产生实战训练感。

### 4.4 搜索知识路径

路径：

首页搜索 → 输入“什么时候炸” → 进入知识点 → 看口诀和案例 → 做练习

目标：

满足“30 秒找答案”。

## 7. AI 教练原型

### 7.1 教练定位

AI 教练是产品的核心角色，不是装饰性吉祥物。

身份：

- 掼蛋教练
- 陪练伙伴
- 决策提示器

性格：

- 专业
- 冷静
- 短句
- 鼓励
- 幽默一点
- 不讲废话

### 7.2 教练语气规范

允许：

- “别急。”
- “先看队友。”
- “这里不能炸。”
- “很好，牌权拿回来了。”
- “这手牌要留后路。”

禁止：

- 大段解释
- 玄学判断
- 过度夸张
- 长篇教学口吻

### 7.3 V1 动作状态

V1 只做 5 个状态：

1. idle：默认站立
2. thinking：思考
3. point：提示重点
4. correct：答对点赞
5. wrong：答错提醒
6. celebrate：课程完成庆祝

复杂动作在 V2 扩展。

## 8. 首批课程目录

V1 建议先做 24 个知识点。

### Lv1 认识规则

1. 掼蛋到底怎么赢
2. 什么是头游
3. 什么是升级
4. 什么是贡牌

### Lv2 识别牌型

1. 单张、对子、三张
2. 三带二
3. 顺子
4. 钢板
5. 炸弹
6. 同花顺

### Lv3 判断牌力

1. 什么是好牌
2. 什么是散牌
3. 大牌该不该留
4. 小牌怎么处理

### Lv4 炸弹使用

1. 什么时候该炸
2. 什么时候不该炸
3. 炸弹换牌权
4. 炸弹保护队友
5. 小炸换大炸值不值

### Lv5 主攻打法

1. 如何抢头游
2. 如何拆牌
3. 如何保持接牌能力
4. 如何逼对手出炸

### Lv6 助攻配合

1. 如何送队友
2. 什么时候让牌
3. 什么时候顶住对手
4. 队友快走完时怎么打

## 9. 首批残局题方向

V1 建议先做 20 道残局。

题型：

1. 该不该炸
2. 该不该让队友
3. 对手剩 1 张怎么拦
4. 队友剩 2 张怎么送
5. 自己牌很散怎么处理
6. 有炸但无牌权怎么打
7. 拿到牌权后先出什么
8. 被压制时怎么脱手
9. 头游和保队友如何取舍
10. 小牌太多如何清理

每道题必须包含：

1. 场景标题
2. 当前等级
3. 四家剩牌数
4. 我的手牌
5. 已出牌历史
6. 三个选项
7. 正确答案
8. AI 教练短反馈
9. 复盘步骤
10. 标签

## 13. 动效原型

V1 只做必要微动画：

1. 页面进入：淡入上移
2. 卡片切换：左右滑动
3. 答对：绿色闪光 + 教练点赞
4. 答错：轻微震动 + 教练思考
5. 完成课程：经验条增长
6. 扑克牌选择：上移 8px

原则：

- 不炫技
- 不影响阅读
- 不牺牲交互速度

